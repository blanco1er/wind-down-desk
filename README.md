# Wind-Down Desk

A hands-first evening wind-down for Meta Quest 3 and 3S, built with the Meta Immersive Web SDK (WebXR).
Say what's on your mind, sort it into engraved stones, let the heaviest one sink, breathe. A living lamp guides you.

The app lives in [`wind-down-desk/`](wind-down-desk/) (see its README to run, test and deploy). MIT licence.

Every measured number (draw calls, cold start, hands-only runs, the bus-stop path on the live site, unknown rooms, field of view) and the command that reproduces it: [`wind-down-desk/MEASUREMENTS.md`](wind-down-desk/MEASUREMENTS.md).
